# 桌面后台准备联网搜索

安装器不再同步下载默认的 `@openclaw/parallel-plugin`。已有插件通过本地校验时保持原样；
需要安装或修复时，安装器保存 `~/.openclaw/microclaw-search-setup.json` 待办，暂时关闭搜索并移除
尚不可用的提供方和插件启用配置，避免影响 Gateway 启动。其他搜索提供方及用户主动关闭的搜索不变。

桌面界面加载、应用服务就绪，且安装升级事务提交后，后台任务每隔 5 秒检查启动条件；
没有活动聊天或模型配置操作时开始准备。它通过现有 Gateway 插件接口安装与当前运行时同版本的
Parallel 插件，热加载后再通过带版本哈希的配置接口恢复搜索设置，不主动重启 Gateway，也不弹窗。

- 下载失败、插件安全审查要求、运行时变化或热加载无法确认时，仅记录 `[web-search]` 日志。
  待办保留，每次桌面启动最多尝试一次，下次启动继续；不会自动确认额外安全审查。
- 用户在准备前或下载期间切换搜索配置时，不覆盖用户的选择。
- 搜索配置确认热生效后删除待办；在此之前普通聊天不依赖搜索，联网搜索暂不可用。
- 待办包含在安装升级的托管状态备份和回滚中；安装器验证桌面就绪不等待该后台任务。
- 应用退出时停止调度；后台任务不通过隐藏窗口或独立安装器进程执行。

需要重新构建桌面包与安装器才会生效。测试以模拟 Gateway 和临时状态目录验证调度、失败恢复、
热加载回执和并发配置保护；真实网络下载和完整安装耗时仍需用新构建的安装包验证。
