## 本次修改

- 设备配对因鉴权拒绝导致连接断开时，保留原来的进程重启。
- 节点授权后，优先使用客户端已有的 `node.pair.resolved` 自动重连机制。
  以同一节点的断开/重新连接或 `connectedAtMs` 增长确认连接更新，并检查新连接的
  命令集合；不会把授权前的旧连接直接算作就绪。
- 保留原进程身份检查和执行环境准入。5 秒内没有确认自动重连时，才使用原来的
  完整进程重启；进程被停止、替换或命令集合异常时仍拒绝继续。
- 新增 `bundled-node-pairing-reconnect` 日志，记录 `same-process` 或
  `restart-fallback`、进程 ID 和等待耗时。
