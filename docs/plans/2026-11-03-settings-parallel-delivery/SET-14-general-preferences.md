# SET-14 语言、字号、通知与聊天交互偏好

阶段：主线 P1/P2；复杂度：M。依赖：SET-01、SET-02。

## 目标与边界

围绕应用偏好完成可持久化、可恢复的体验设置，不与 Gateway 配置混写。主责 A01–A06；已有主题 A02 只回归，主题导入/自定义颜色体系 A04 暂缓。

## 实施范围

1. 复核隐藏语言入口、中英资源、tray 更新和 app settings 持久化；正式支持语言切换时补齐裸 key/缺失翻译，不只放出下拉框。
2. 提供有界字号/聊天内容宽度等轻量展示偏好，使用现有样式体系，默认保持当前布局，不全量更换设计系统。
3. 聊天发送快捷键提供明确可选行为，正确处理中文输入法 composition、换行、无障碍和快捷键冲突。
4. 通知偏好只控制有实际来源的完成/失败等事件；区分应用设置、系统权限和前后台行为，拒绝系统权限不应阻塞使用。
5. 偏好校验/迁移/重置走 app settings 的安全白名单；保留 autoStart、minimizeToTray 和主题行为，不写 OpenClaw 配置。

## 写入范围

- 独占新增：`desktop/renderer/src/components/settings/general/`、偏好专用 composable/utilities、`desktop/src/settings/preferences/` 及测试。
- 聊天展示/快捷键需要时独占 `views/ChatView.vue` 及对应测试的本任务相关改动；不改 `stores/chat.ts` 隐私路径。
- 通用区块替换、根级 i18n/主题全局接线交 SET-01；settings 白名单/通知系统 IPC/类型交 SET-02。
- 与 SET-01 对齐搜索和文案接入，不在各页面建立另一套语言存储。

## 验收

- [ ] 中英切换、重启恢复、旧用户无新字段的默认值和非法值恢复有测试。
- [ ] 字号/宽度在窄窗口、长消息、深浅主题下不破版，键盘可用，默认视觉不发生无关重构。
- [ ] Enter/修饰键/换行与 IME 组合用例正确，不双发或发送组合中的汉字。
- [ ] 通知关闭/系统拒绝/聚焦/后台/重复完成事件不误发；内容默认不泄露聊天正文。
- [ ] 自动启动/托盘/主题原行为不回归；应用偏好不触发 Gateway 重启或修改工具权限。

非目标：皮肤市场、任意主题导入、消息模板系统、全局热键服务、改变命令同意模式。范围较低优先，可在 P0/P1 关键领域之后排期，不影响主线安全基础完成。
