# SET-09 会话作用域、上下文、保留与导出

阶段：主线 P1；复杂度：L。依赖：SET-01、SET-02、SET-03。

## 目标与边界

把会话生命周期、上下文成本和历史操作放在同一领域闭环内。主责 C08–C14；既有 pin/new/delete/reset 只回归，C13 系统心跳/并发编排和 C14 外部迁移/记忆导入暂缓。

## 实施范围

1. 对固定 Runtime 支持的会话覆盖、身份/隔离、reset 策略建立显式配置与来源说明；模型字段直接复用 SET-08。
2. 提供已验证的 compaction/context pruning/budget 常用项，显示默认/继承；未广告字段不可编辑，不透传任意 Schema。
3. 历史保留与维护分开“策略配置”和“立即删除”；展示影响会话/时间范围，删除须确认，不暗示可撤回供应商已收到的数据。
4. 会话导出复用受控历史查询，包含明确范围和导出时间；附件、工具结果与敏感内容默认处理明确，不借导出读取任意磁盘文件。
5. 处理流式生成中、会话已删、Agent 切换、查询翻页和删除后的缓存失效；旧响应不得恢复已删除记录。

## 写入范围

- 独占新增：`desktop/src/settings/sessions/`、`desktop/renderer/src/components/settings/sessions/` 和独立会话设置 store/composable 及测试。
- `stores/chat.ts` 的隐私路径由 SET-05 独占，本任务只读复用公共历史/会话接口；需要缓存失效/事件接点向 SET-02 提交最小请求。
- `SidePanel.vue` 的菜单接线交 SET-01；主进程 session handlers/类型交 SET-02。
- 模型策略 SET-08、用量查询 SET-11、工具策略 SET-03/10 各有独立来源，不在此保存另一份。

## 验收

- [ ] 无覆盖、全局默认、Agent 默认、会话覆盖以及会话切换的最终值/来源可解释。
- [ ] Runtime 不支持、保护阻断、离线与数据不存在分别处理；不把空结果当保存成功。
- [ ] 修改上下文参数保留其他配置；并发/外部修改冲突可重试且不静默覆盖。
- [ ] 合成历史覆盖保留阈值、时区、翻页、运行中会话、确认取消与清理后的缓存一致性。
- [ ] 导出范围与查询一致，附件/工具/秘密处理有证据，不读取未授权文件。
- [ ] 原新建/固定/删除/重置及会话模型切换无回归；不改聊天隐私发送链。

非目标：实现新的压缩算法、记忆索引、外部产品会话迁移、后台 Agent 编排、跨渠道身份系统。缺少必要安全 RPC 的写操作单列未交付，不用通用文件写模拟。
