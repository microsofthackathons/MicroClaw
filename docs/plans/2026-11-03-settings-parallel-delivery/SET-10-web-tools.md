# SET-10 联网搜索、网页读取与安全保存闭环

阶段：主线 P1；复杂度：M。依赖：SET-01、SET-02、SET-03。

## 目标与边界

让现有提供方/Key 设置真正做到安全保存和可验证生效，并补联网工具常用控制。主责 F01–F04；不包含浏览器自动化。

## 实施范围

1. 复核 `SettingsView.vue` 搜索的读取、保存和翻译提示：旧路径整份 `config.write`、替换 `tools.web.search` 及保护模式写入限制必须单独验证。
2. 为固定 Runtime 认可的搜索开关、提供方、凭据、自动路由、最大结果/超时/缓存及网页读取开关/限制建立 typed adapter；不支持的项明确禁用。
3. 只修改本任务字段，保留已有高级字段、其他 providers、Header、凭据引用与未知配置，不因简单保存清空整棵对象。
4. MXC 允许的联网设置通过受控变更路径；无法安全支持的操作明确只读，不能放宽通用写接口或绕过策略。
5. 保存后核对实际配置与运行态；热加载/重启提示与真实结果一致，区分 Key 未配、认证失败、限额、网络和策略阻断。
6. 迁移到工具分组时保留原模型页搜索位置的跳转；已有 `parallel-free`、Brave、Tavily 不回归。

## 写入范围

- 独占新增：`desktop/src/settings/web-tools/`、`desktop/renderer/src/components/settings/web-tools/` 及测试。
- 原 `SettingsView.vue` 搜索区/函数替换和旧入口跳转交 SET-01；config/IPC 接线交 SET-02。
- SET-03 提供有效状态组件；SET-17 未上线前沿已有专用凭据语义安全保存，不自行发明明文密钥中心。
- 不改搜索插件执行逻辑、工具沙箱或浏览器策略；若固定 Runtime 字段差异妨碍写入，提交具体能力证据。

## 验收

- [ ] 合成旧配置含额外搜索字段/未知 providers/SecretRef，修改提供方或单个限制后均保留无关内容。
- [ ] 普通/适用保护模式分别测试安全提交和实际生效；拒绝时草稿保留且原因正确。
- [ ] 未支持的缓存/超时/路由字段不可假装开启；修改不偷偷启用整个工具 profile。
- [ ] Key 不回显到查询、日志、错误和测试快照；测试连接需确认且使用 mock/隔离样本。
- [ ] 并发冲突、断连、重启失败、取消与旧请求回流有用例；成功提示只在验证后出现。
- [ ] 旧入口可找到新位置，现有三类提供方及未配置状态无回归。

非目标：网页浏览器、任意 HTTP 代理、替换搜索供应商插件、改变联网安全边界、强制联网或自动付费调用。
