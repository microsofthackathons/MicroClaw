# SET-02 受控配置提交契约、冲突与恢复

阶段：主线 P0；复杂度：L。依赖：无。产物里程碑：`CFG-M1`。

## 目标与边界

为设置域建立可靠的读取、提交、冲突和生效语义，避免新增功能继续整份回写配置。主责 A08、G13；不是把所有设置转换成一个任意 JSON 编辑器。

## 实施范围

1. 复核 `model-config-application.ts`、`windows-node-mxc-model-config.ts`、`config-write-policy.ts` 和目录事务；保留现有模型的 `baseHash`、generation、验证和恢复保证。
2. 冻结脱敏快照、稳定目标、修订、域操作、错误和应用阶段 DTO；分开应用偏好、Gateway 配置、受管文件、凭据的存储语义。
3. 实现最小公共校验/协调机制与显式域 adapter 注册方式；支持跨域冲突，防止两个面板都基于旧快照覆盖同一底层文件。
4. 明确保存、运行态确认、需要重启、结果未知、恢复失败的状态；不具备安全 adapter 的域明确不可写。
5. 主进程校验 IPC 来源、payload/大小/字段/作用域和运行状态；只读结果不携带秘密原文。

## 写入范围与接线职责

- 独占新增：`desktop/src/settings/core/`、公共契约及对应测试；公共类型物理布局必须通过两端 TS 构建。
- 共享后端唯一写入方：`desktop/src/main.ts`、`desktop/src/preload.ts`、`desktop/renderer/env.d.ts`、`desktop/renderer/src/browser-openclaw.ts`；为功能 registrar 做最小接线。
- 既有模型应用/配置策略公共接点由本任务维护回归；功能需求使用自己的域 adapter，不直接改这些模块。
- MXC、命令同意、目录事务、执行授权和升级证明的行为变更需原安全维护者审查；本任务没有放宽权限的授权。

## 交付与协作

- CFG-M1 是“契约冻结 + 现有模型路径回归 + 最小可编译接入示例”，不是所有领域写操作已经实现。
- 后续任务提供域 registrar、校验器、预加载客户端切片、DTO 和 browser mock 请求，由本负责人集中注册。
- 搜索保存的实际业务修复归 SET-10；模型策略归 SET-08；受管文件版本化归 SET-07，避免公共基础吞掉领域责任。

## 验收

- [ ] 合成配置中的未知字段、Header、插件配置、SecretRef 不因修改简单字段消失。
- [ ] 同域/跨域并发、外部配置变更、旧 generation、断连、重复提交均不静默覆盖。
- [ ] MXC 下未允许写入仍被拒绝；不存在通用 RPC/原始文件后门。
- [ ] 故障注入覆盖写前失败、保存后未生效、超时结果未知、恢复冲突和恢复失败。
- [ ] 全局、Agent、会话和应用偏好目标不混淆；新契约不会削弱现有模型/目录事务。
- [ ] 配置查询、错误、日志与 mock 快照中不包含合成秘密原值。

非目标：一次性迁移所有旧代码、重写模型应用服务、扩大 `config:write` 白名单、自动升级 OpenClaw、实现各领域 UI。
