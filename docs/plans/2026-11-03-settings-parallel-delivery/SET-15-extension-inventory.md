# SET-15 插件只读清单、版本与准入说明

阶段：主线 P1；复杂度：M。依赖：SET-01、SET-02、SET-03。

## 目标与边界

提供真实的“已安装/请求启用/允许/实际加载”扩展清单，避免把只有微信卡片的页面误称完整插件中心。主责 D06；插件写入和 MCP 执行留给 SET-18。

## 实施范围

1. 从受控 Runtime/插件 metadata 汇总来源、版本、路径归属、完整性/准入状态、加载结果与错误；未知要标注，不能扫描任意用户目录。
2. 区分包存在、配置请求、允许列表、实际加载和受保护模式阻断，复用 SET-03 语义。
3. 提供只读详情、配置 Schema 是否存在、依赖/凭据是否缺失的遮罩说明；不把含 secret 的原始 Schema 值回传 renderer。
4. 保留微信连接入口并复用 SET-13 卡片/链接；导出简化版本 manifest 给 SET-04 诊断，不复制下载/更新逻辑。
5. 安装/更新/卸载/启用按钮不做假可用；明确后续安全准入和不可用原因。

## 写入范围

- 独占新增：`desktop/src/settings/extensions/`、`desktop/renderer/src/components/settings/extensions/` 及测试。
- 既有域独占：`views/PluginsView.vue` 及相关测试；微信卡片本身归 SET-13，只复用。
- plugin lifecycle/convergence/完整性和 MXC 允许列表只读；main/preload 接线交 SET-02，分组路由交 SET-01。
- SET-18 用单独 `extension-admission` 目录处理变更；若二期要扩展本清单，由本任务完成后显式交接，不能并行同改。

## 验收

- [ ] 未安装、仅有包、被禁用、准入受限、加载失败、metadata 缺失/损坏有用例。
- [ ] 打开和刷新清单不安装、更新、修复、加载未批准插件或执行插件代码来取 metadata。
- [ ] 秘密/环境变量不回显；路径/错误脱敏，受控读取有界且拒绝越界重解析点。
- [ ] 微信现有连接可达，SET-04 能消费版本摘要；版本无法读取时明确未知。
- [ ] 保护模式下实际允许状态准确；不靠写 `plugins.allow` 让测试变绿。

非目标：插件市场、签名/信任基础设施新实现、安装器、配置写入、MCP/记忆执行。只读清单是独立完成的主线交付，不能被误报为通用插件管理已完成。
