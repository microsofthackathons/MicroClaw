# SET-01 设置入口、分组、搜索与共享 UI 接线

阶段：主线 P0；复杂度：M。依赖：无。产物里程碑：`UI-M1`。

## 目标与边界

让后续面板通过同一正式设置入口被发现、搜索和挂载；把 UI 共享接线集中到一个负责人，而不是先重写整个设置页。主责能力 A07，承接 A08 的公共表现。

## 实施范围

1. 确认稳定 section ID 与八组映射：通用、模型、智能体与技能、连接、自动化、安全与隐私、用量、系统。先用轻量分组，不强制同时改完所有导航样式。
2. 最小 typed feature 接入：组件、组、标题、关键词、状态。旧面板可保留兼容壳，领域任务交付时再替换旧区块。
3. 设置搜索支持标题、同义词和中英文；命中不可用功能时可看到原因/安全下一步，不变成隐藏功能开关。
4. 兼容 `/settings/:section?`、`/skills`、`/phone` 等旧链接；开发专有页不因搜索/路由而意外开放。
5. 冻结域内文案接入、未保存草稿离开提示、加载/空态/错误/只读的公共 UI 约定。

## 写入范围与接线职责

- 独占新增：`desktop/renderer/src/components/settings/shell/`、设置 feature 注册表、壳级测试。
- 共享 UI 唯一写入方：`desktop/renderer/src/views/SettingsView.vue`、`router.ts`、`App.vue`、`components/SidePanel.vue`、根级 `i18n` 注册/资源；仅修改本任务及已批准的功能接线。
- 现有导航测试由本任务维护；领域组件原有测试由领域任务维护。
- 不改 `main.ts`、`preload.ts` 或任何安全策略。需要 DTO 时按 CFG-M1 接口协商，不建立新业务服务。

## 交付与协作

- UI-M1 交付一个最小可编译面板示例和接线清单；后续任务依赖这个里程碑，而非全部功能合并。
- 提供每个领域的 section ID、文案 namespace 和挂载导出约定；这些是协作契约，不是由每个 Agent 自行起名。
- 基础任务关闭后负责人仍担任共享 UI 接线协调者；每个领域提交的导入/注册/替换请求随该领域一起验收。

## 验收

- [ ] 正式构建中原有七分区仍可用，默认路由和旧书签不会落到空白页。
- [ ] 搜索、键盘操作、焦点、中文/英文、深色/浅色均有用例；受限项原因不是裸翻译 key。
- [ ] 路由切换能提示未保存草稿，不会把 Agent A 草稿挂到 Agent B。
- [ ] 未注册/非法 section 安全回退；DEV 技能入口不会因重构提前对生产开放。
- [ ] 外壳接入不发送配置写入或自动重启 Gateway。

非目标：业务字段、重新设计整套聊天 UI、建立通用动态插件加载器。交付报告列出 UI-M1 契约及共享文件变更位置，便于下一批 Agent 接入。
