# SET-20 专家级只读配置、Schema 与差异检视

阶段：二期 P2；复杂度：M。依赖：SET-01、SET-02、SET-03、SET-04。不需要先开放任意配置写入。

## 目标与边界

给支持排障人员一张可检视来源/覆盖/限制的配置视图，而不是给普通用户一个能绕过所有策略的 raw editor。主责 G03、G12；G14 的采集/日志配置仅只读检视，实际采集边界归 SET-04。

## 实施范围

1. 读取 Runtime 实际广告的 Schema 与受控脱敏快照，展示版本、来源、未知/插件字段和能力限制；离线不展示假默认值。
2. 区分配置原请求、应用受管覆盖、Agent/会话覆盖和实际运行态；受支持时可比较修订差异，标注未读取/不可确定部分。
3. 提供只读 raw/树状/搜索，敏感字段和值在主进程就去掉或遮罩，不能只在 renderer 隐藏。
4. 服务端绑定/认证/TLS/日志/遥测配置仅显示安全摘要和管理来源；不接受更改网络公开面、令牌、环境变量或任意文件路径。
5. 对支持正式编辑的域跳转其设置页；域尚未支持时解释原因，不新增万能“保存 JSON”。

## 写入范围

- 独占新增：`desktop/src/settings/config-inspector/`、`desktop/renderer/src/components/settings/config-inspector/` 及测试。
- 消费 SET-02 读取/修订、SET-03 状态和 SET-04 脱敏/版本契约；不用通用 `config.read` 原样回传到新页面。
- UI 注册交 SET-01、只读 IPC/类型交 SET-02；不改配置写入策略、安装/更新逻辑或网络监听。

## 验收

- [ ] 固定 Runtime、Schema 缺失/变化、离线/权限不足和未知字段显示正确，不宣称全域可编辑。
- [ ] 大 Schema/配置有大小/递归限制，不加载未批准插件代码来获得表单。
- [ ] 合成秘密藏于标准字段、Header、query、插件嵌套/未知字段时不泄露；不安全字段无法可靠脱敏则不返回值。
- [ ] 请求值/受管覆盖/有效状态和版本来源可分辨，旧快照标明过期。
- [ ] 页面所有操作均只读，不能通过深链接、导入、快捷键或隐藏按钮发起配置写入。
- [ ] 已支持领域的跳转可用；没有通过其他域安全 adapter 的字段保持不可编辑。

非目标：全域 Schema 编辑器、配置导入写入、任意原始快照导出、远程 Gateway 管理、令牌配对、打开网络端口或改变保护模式。未来若要支持 raw 写入，必须另立安全设计和任务。
