# 85 项能力归属与范围账本

来源为 [差异报告](../../reference/openclaw-web-ui-settings-gap-2026-11-03.md) 的 A01–G14。每行只有一个主责任务；依赖/协作不等于多名 Agent 同改一个领域。

## 如何读

- **主线**：16 个主线任务内交付的已限定范围；仍须 Runtime/安全验证，不等于上游字段全量开放。
- **保留**：已有能力回归，不当作缺失重新实现；“保留/修复”允许修复已核实的领域保存问题。
- **审计**：交付覆盖事实、合成测试、准确说明与已承诺范围内的局部修复，不自动承诺全链路新防护。
- **只读**：交付现状/受限原因/检视，不交付新执行能力；SET-20 为二期只读，SET-03/13 等为主线说明。
- **条件**：产品/安全决策及能力验证后才实现，未决不能标“功能完成”。
- **暂缓/另案**：不在本轮实施；`—` 表示没有被强塞进任一 Agent 的验收义务。

## 完成的判定

能力行可能同时包含“本轮子集”和“暂缓部分”，验收必须使用最后一列限定范围。不得把只读/保留/审计数量计作新增可执行功能数量。任务未决部分与 Runtime 不支持项需要在任务交付报告中明确，不通过改写本表抹去缺口。
