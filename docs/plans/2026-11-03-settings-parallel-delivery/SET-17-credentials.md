# SET-17 凭据存储、引用、替换与删除

阶段：二期 P2；复杂度：L。依赖：SET-01、SET-02、SET-05。产品/安全门控：D3。

## 目标与边界

统一“秘密怎么保存/引用/撤销”的安全语义，而不是把散落的 Key 收集成明文列表。主责 F12、D04，并为 B13 提供可靠认证 metadata；不负责所有供应商 OAuth 和实时额度。

## D3 必须先确定

- 当前 Windows 产品的本地凭据后端、威胁模型、进程可读边界，以及其他平台不支持时的行为。
- 凭据引用的生命周期、备份/迁移/卸载语义、替换/删除影响、已有明文配置的迁移确认。
- SecretRef 与固定 Runtime 的真实兼容性；没有安全引用解析链路时不能只生成一个字符串标识。

未决时只交付设计、合成原型和风险清单；不得上线新明文库或改真实用户 Key。

## 实施范围

1. 安全输入→保存→返回引用/遮罩 metadata；读取接口不返回保存后的秘密，修改分为不变、替换、明确删除。
2. 提供提供方/搜索/技能环境凭据适配；先接已验证的消费路径，再提供统一 UI，不一次性替换全部 auth 结构。
3. 旧值迁移须事务化、可检测重复、可恢复且保留未知字段；失败不能丢失已有连接或同时留下多份泄露副本。
4. 展示引用使用者与删除影响，避免删除仍被使用的凭据；环境变量只暴露名称/是否满足，不批量展示整个进程环境。
5. 失败/日志/审计/导出不回显秘密；Runtime 需要使用凭据不等于 renderer 有权读取。

## 写入范围

- 独占新增：`desktop/src/settings/credentials/`、`desktop/renderer/src/components/settings/credentials/` 及 synthetic fixtures/tests。
- 提供公开 credential-reference adapter 给 SET-08/10/18；不改其他任务面板，可由拥有者接入或完成后显式交接。
- 安全存储依赖/系统 API 选型先评审；main/preload/白名单和 DTO 接线交 SET-02，UI 注册交 SET-01。

## 验收

- [ ] payload、错误、日志、IPC debug、存储 metadata、导出和快照均不包含合成秘密原值。
- [ ] 不变/替换/删除、引用仍使用、权限不足、存储失败和进程重启有明确结果。
- [ ] 迁移失败/重复迁移/外部修改并发可恢复，不破坏已有模型、搜索或技能配置。
- [ ] 引用能在指定 Runtime/保护模式下实际消费；不支持的消费者不能标为已接入。
- [ ] D3 决策、威胁模型、迁移范围和已验证平台记录在交付中。

非目标：企业 KMS、跨设备同步、任意 env 编辑、OAuth 全家桶、所有来源数据的 DLP。未过 D3 只能标“设计完成”，不能标“凭据中心可用”。
