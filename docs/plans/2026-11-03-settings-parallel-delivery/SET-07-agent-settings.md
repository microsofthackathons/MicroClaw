# SET-07 Agent 身份、指令文件与受管工作区

阶段：主线 P1；复杂度：L。依赖：SET-01、SET-02、SET-03。

## 目标与边界

把“只能选预置角色”补成可管理的个人助手，但不建设任意磁盘编辑器。主责 C01–C07，其中 C01/C02 是回归，C07 只做能力聚合；模型默认值与技能变更分别由 SET-08/06 负责。

## 实施范围

1. 复用 `AgentMarketView.vue`、`stores/agents.ts`、agent roster/personas/catalog 的受管 Agent 身份和所有权逻辑。
2. 在安全支持范围内新建自定义 Agent、修改名称/头像/身份说明/指令；保留预置角色添加/移除和现有 session 关联语义。
3. 对应用明确管理的指令文件提供读取、编辑、版本冲突、差异确认和恢复；文件名单及根目录由主进程限定。
4. 工作区/cwd/repoRoot 显示来源和目录权限；允许选择不等于授予读写，不能因创建 Agent 自动扩大批准目录。
5. 聚合当前 Agent 的有效工具、技能和模型来源；编辑入口调用对应任务公开面板，不重复实现模型/技能保存。
6. 已有会话、运行中任务、被删除 Agent、只读/不可用工作区有明确处理；不能把草稿应用到当前选中的另一个 Agent。

## 写入范围

- 独占新增：`desktop/src/settings/agents/`、`desktop/renderer/src/components/settings/agents/` 及测试。
- 既有域独占：`views/AgentMarketView.vue`、`stores/agents.ts` 及其测试；agent roster/persona 文件如需改变已有语义，列具体改动交 SET-02 审查。
- 主入口、侧栏、路由交 SET-01，Agent IPC/类型接线交 SET-02；不改 `stores/chat.ts` 或目录授权事务。
- 受管文件事务实现属于本任务，使用 CFG-M1 冲突/错误约定，不假设普通配置 adapter 可以安全写任意文件。

## 验收

- [ ] 全新自定义 Agent 和已有预置 Agent 的身份保持稳定，更新不会改错别的 Agent/会话。
- [ ] 指令文件外部修改触发冲突；恢复前检查新版本，不覆盖其他客户端后续修改。
- [ ] 拒绝路径穿越、绝对路径注入、越界符号链接/重解析点和未经批准文件；测试覆盖大小/编码/缺失。
- [ ] 工作区不可用/只读时明确提示，不悄悄把目录加入全局读写；保护状态与显示一致。
- [ ] 删除确认解释对会话/文件的影响；新建失败不留下错误的 roster 或半创建目录。
- [ ] 模型/技能入口复用 SET-08/06 契约，不创建第二份状态来源。

非目标：任意文件管理、源码 IDE、跨 Agent 数据迁移、为 Agent 赋任意工具、自动放宽目录策略。若固定 Runtime 不支持某字段，记录并降级只读，不能假装保存成功。
