# SET-11 用量详情、查询筛选与一致导出

阶段：主线 P1；复杂度：M。依赖：SET-01、SET-02。

## 目标与边界

把已有详细数据层/未挂载界面接到正式入口，交付能筛选和导出的用量分析。主责 G09、G10；G09 以保留原汇总为主，不把统计功能扩展成强制预算控制。

## 实施范围

1. 复核 `UsagePanel.vue`、`useUsagePanel.ts`、usage service/snapshot cache 与 preload 详细查询接口，优先复用数据层。
2. 日期范围、Agent/会话/模型等筛选按后端实际能力展示；不能只改前端标签而查询仍是固定 30 天。
3. 明细/汇总/翻页/导出使用一致的查询模型和时间边界；切换筛选时取消或隔离旧结果。
4. 明确 token/请求/费用来源、估算属性、币种和汇率时间，不把未提供费用算成已知 0。
5. CSV/JSON 导出标注查询、时间窗、时区和口径；必要内容脱敏，不导出消息正文/凭据。

## 写入范围

- 独占新增：`desktop/src/settings/usage/`、`desktop/renderer/src/components/settings/usage/` 及测试。
- 既有域独占：`components/UsagePanel.vue`、`composables/useUsagePanel.ts` 及对应测试；usage-service/cache 若需变更，限本任务查询/缓存行为并记录兼容性。
- 主入口挂载交 SET-01，主进程/预加载接线交 SET-02；不用 `SettingsView.vue` 堆新查询逻辑。
- SET-09 拥有历史删除/保留；本任务消费其已确认数据变化，不直接删会话数据或改聊天 Store。

## 验收

- [ ] 正式用量入口可达；原 30 天概览、模型合计和原币值口径不回归。
- [ ] 空数据、跨日/时区、部分缺费用、超过单页、离线/失败和缓存过期有合成测试。
- [ ] 快速切换筛选、旧请求晚返回、导出中切换条件，不混入别的查询结果。
- [ ] 导出与屏幕查询范围一致，CSV 对公式注入做安全处理，JSON/文件名不含秘密。
- [ ] 可解释统计延迟/估算和汇率；不显示可生效的预算开关。

非目标：计费系统、供应商实时账单同步、预算强制停用、补造历史数据。现有 `maxBudget: null` 不能作为已有预算能力的证据；预算另立产品需求。
