## 包含的 Feature

### 1. Chat 欢迎页（ChatWelcome.vue）

用户打开聊天、还没有发过任何消息时显示的欢迎界面，有两种模式：

**Hero 模式**（新建会话时展示）
- 大标题 + 副标题问候语
- 扇形卡片排列，每张卡片对应一个使用场景（配有角色插图）
- 点击卡片自动填入对应的 prompt，引导用户开始对话

**Compose 模式**（输入框聚焦时展示）
- 输入框下方显示快捷建议 pill
- 左右滚动浏览更多建议
- 点击 pill 自动填入 prompt

---

### 2. 主导航栏（PrimaryNav.vue）

窗口左侧的图标导航栏，包含以下 tab：
- **对话** — 进入聊天页
- **任务** — 进入任务列表页
- **手机** — 手机联动（预留）
- **探索** — 技能/模板探索（预留）

选中 tab 时图标切换为实心填充样式。底部保留用户头像位置。

---

### 3. 侧边栏任务锚点（useMvpTasks.ts）

用户在聊天中发送消息后，该消息作为任务标题自动出现在侧边栏 Agent 名字下方，方便快速回跳。

- 每条任务取用户消息前 24 个字符作为标题
- 点击任务条目跳转回对应对话
- 支持多条任务并列展示，可展开/收起

---

### 4. 导航状态管理（useNavState.ts）

管理当前激活的 tab（chat / tasks / phone / explore），供导航栏和侧边栏共享使用。
